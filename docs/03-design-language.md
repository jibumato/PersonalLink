# PersonalLink デザイン言語「GLASS-HUD」

**Version 0.2 / 2026年8月**(v0.1のダーク「NEON-HUD」からオーナー指定で**白ベース**へ変更。プロトタイプ v0.2 が実装リファレンス)

構想書 Phase 6(ARグラス)を見据えたビジュアル言語。

---

## 1. コンセプト

**「UIは視界を塞がない」— 見ながら、使える。**

- 将来のARグラスでは、UIの背後に**実世界**がある。UIが視界を占有した瞬間、歩けない・話せない・危ない
- したがってすべてのパネルは**半透明の白ガラス**とし、背後が常に透ける。スマホ/Web(Phase 1〜2)の段階からこの原則で作り、AR移行時にUI言語を変えずに済むようにする
- プロトタイプではデータストリーム流体背景が「実世界の代役」。**AR透過モード**(パネル不透明度スライダー 15〜85%)で、透過度を変えたときの視認性を検証できる
- 地は白: 明るい環境でのAR(屋外・イベント会場)では加算的な発光UIより、**淡い地+濃い線**の方が読める。未来感は「発光」ではなく「形状(チャンファー・ブラケット)と流体」で出す

## 2. 背景: データストリーム流体

- フローフィールド(重ねた sin/cos 波で角度場を作る)に沿って粒子の**流線**を描画。通信=データの流れ、のメタファー。白地に細いペンストロークのように走る
- 低透明度の**グリフ**(カナ・16進)が同じ場を漂う
- 実装: Canvas 2D、粒子 ≦200(画面面積/13000でスケール)、ストローク透明度 .34、残像フェード `rgba(238,244,246,.10)`、DPR上限1.5、`prefers-reduced-motion` 時は静止画1枚、非表示タブでは停止
- 色の配分: ティール 74% / グリーン 12% / マゼンタ 9% / アンバー 5%(アンバーは希少色として効かせる)

## 3. カラートークン

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#eef4f6` | 地(シアンに寄せた白) |
| `--a-brand` | `#0891b2` | ティール。主操作・アクティブ状態・HUD線 |
| `--a-deep` | `#0e7490` | 濃ティール。強調テキスト・CTA文字(`#045a6d`) |
| `--a-ink` | `#12262e` | 本文(シアン寄りの墨) |
| `--a-mut` | `#5b7a84` | 補助テキスト |
| `--a-amber` | `#8a6a00` 文字 / `rgba(245,217,10,.2)` 地 | イエロー系。**時間・期限**(残り日数、期限バナー、ミュートON)。CTAは原色 `#f5d90a`+墨文字 |
| `--a-green` | `#0f9d6a` | グリーン。**恒久・成功** |
| `--a-red` | `#d6455d` | 危険(ブロック・通報・エラー) |
| `--glass` | `0.62`(可変) | 白パネル不透明度。AR透過モードで 0.15〜0.85 |

意味の対応は不変: **時間=イエロー系、恒久=グリーン、主操作=ティール**。

## 4. 形状・質感

- **チャンファー(角落とし)**: 主要ボタンは `clip-path` で対角2隅を12pxカット
- **コーナーブラケット**: カード類は対角2隅に L字マーク(照準/ロックオンのメタファー)
- **スキャンライン**: 画面全体に3px周期の走査線オーバーレイ(`rgba(10,60,80,.02)`、操作は透過)
- 罫線は1px `rgba(8,145,178,.14〜.4)`。白地では発光(text-shadow)を使わず、**濃度コントラストとソフトシャドウ**で階層を作る
- QRコードは白地に墨セル(実スキャン可能性を最優先。QR領域だけは透過させない)
- カメラビューだけは暗い(現実のファインダー)
- 数値・ID・タイムスタンプ・マイクロラベルは等幅(`ui-monospace` スタック)+レタースペーシング

## 5. 透過の原則(AR-ready)

1. パネル背景は必ず `--glass` を参照する(直値のrgbaで塗らない)
2. 文字の可読性はパネルの濃さに依存させず、**インセット1px線+文字色コントラスト**で担保する(透過度を下げても読める)
3. `backdrop-filter: blur(8〜12px)` は「背後が見えつつ文字が読める」ための道具。ARでは弱める前提
4. 全面を覆うモーダルでも背景を完全遮蔽しない(オーバーレイの暗幕は `rgba(18,45,56,.32)` まで)
5. スマホベゼルはリング塗りのみ(画面内部は背景が透ける=「端末は窓」)

## 6. モーション

- 常時動くのは背景ストリームのみ。UI側のアニメーションは**状態変化の瞬間だけ**(成立時の点滅イン `neonin` など)
- `prefers-reduced-motion: reduce` では背景は静止画、UIアニメーションは無効

## 7. 本実装に向けた注意(アクセシビリティ)

- WCAGコントラスト: 本文 `#12262e` は白ガラス上でAAAを維持。補助文字 `#5b7a84` は `--glass ≧ 0.5` でAA相当。**設定に「高コントラストモード」(透過を固定で上げる)を用意する**こと
- 走査線・背景ストリームはユーザー設定でOFFにできること
- カラーのセマンティクス(イエロー=時間など)は色以外の手掛かり(アイコン⏳♾)と常に併用する(色覚多様性対応)
