# PersonalLink デザイン言語「NEON-HUD」

**Version 0.1 / 2026年8月**(プロトタイプ v0.2 で導入)

構想書 Phase 6(ARグラス)を見据えたビジュアル言語。プロトタイプ `prototype/index.html` が実装リファレンス。

---

## 1. コンセプト

**「UIは視界を塞がない」— 見ながら、使える。**

- 将来のARグラスでは、UIの背後に**実世界**がある。UIが視界を占有した瞬間、歩けない・話せない・危ない
- したがってすべてのパネルは**半透明**とし、背後が常に透ける。スマホ/Web(Phase 1〜2)の段階からこの原則で作り、AR移行時にUI言語を変えずに済むようにする
- プロトタイプではデータストリーム流体背景が「実世界の代役」。**AR透過モード**(パネル不透明度スライダー)で、透過度を変えたときの視認性を検証できる

## 2. 背景: データストリーム流体

- フローフィールド(重ねた sin/cos 波で角度場を作る)に沿って粒子の**流線**を描画。通信=データの流れ、のメタファー
- 低透明度の**グリフ**(カナ・16進)が同じ場を漂う
- 実装: Canvas 2D、粒子 ≦200(画面面積でスケール)、DPR上限1.5、`prefers-reduced-motion` 時は静止画1枚、非表示タブでは停止
- 色の配分: シアン 74% / ミント 12% / マゼンタ 9% / イエロー 5%(イエローは希少色として効かせる)

## 3. カラートークン

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#04090d` | 最深部の地 |
| `--a-brand` | `#5ee9f2` | シアン。主操作・アクティブ状態・HUD線 |
| `--a-deep` | `#9ff6ff` | 明シアン。強調テキスト |
| `--a-ink` | `#e6f7f9` | 本文 |
| `--a-mut` | `#89aeb7` | 補助テキスト |
| `--a-amber` | `#f5d90a` | イエロー。**時間・期限**(残り日数、期限バナー、ミュートON) |
| `--a-green` | `#3ef0a5` | ネオンミント。**恒久・成功** |
| `--a-red` | `#ff5468` | 危険(ブロック・通報・エラー) |
| `--glass` | `0.62`(可変) | パネル不透明度。AR透過モードで 0.15〜0.85 |

意味の対応は従来と不変: **時間=イエロー、恒久=グリーン、主操作=シアン**。セマンティクスを変えずに衣装だけ替えた。

## 4. 形状・質感

- **チャンファー(角落とし)**: 主要ボタンは `clip-path` で対角2隅を12pxカット。CP系HUDのシグネチャ
- **コーナーブラケット**: カード類は四隅のうち対角2隅に L字マーク(照準/ロックオンのメタファー)
- **スキャンライン**: 画面全体に3px周期の走査線オーバーレイ(不透明度3%以下、操作は透過)
- 罫線は1px、`rgba(シアン, .12〜.4)`。グローは `text-shadow` / `box-shadow` で控えめに(発光は情報のある場所だけ)
- 数値・ID・タイムスタンプ・マイクロラベルは等幅(`ui-monospace` スタック)+レタースペーシング

## 5. 透過の原則(AR-ready)

1. パネル背景は必ず `--glass` を参照する(直値のrgbaで塗らない)
2. 文字の可読性はパネルの濃さに依存させず、**インセット1px線+文字色コントラスト**で担保する(透過度を下げても読める)
3. `backdrop-filter: blur(8〜12px)` は「背後が見えつつ文字が読める」ための道具。ARでは弱める前提
4. 全面を覆うモーダルでも背景を完全遮蔽しない(オーバーレイは `rgba(…, .55〜.6)` まで)

## 6. モーション

- 常時動くのは背景ストリームのみ。UI側のアニメーションは**状態変化の瞬間だけ**(成立時のネオン点滅イン `neonin` など)
- `prefers-reduced-motion: reduce` では背景は静止画、UIアニメーションは無効

## 7. 本実装に向けた注意(アクセシビリティ)

- WCAGコントラスト: 本文 `--a-ink` は `--glass ≧ 0.5` でAA相当を維持。**設定に「高コントラストモード」(透過を固定で上げる)を用意する**こと
- 走査線・グローはユーザー設定でOFFにできること
- カラーのセマンティクス(イエロー=時間など)は色以外の手掛かり(アイコン⏳♾)と常に併用する(色覚多様性対応)
