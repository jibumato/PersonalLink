# 名称検討メモ — People OS を続投するか

**Version 0.1 / 2026-08-13**

プラットフォーム名「People OS」について、**改名候補と「このまま」の両方**を検討した記録。

> ⚠️ 本メモの衝突調査は **Web検索とDNSの簡易確認**(2026-08-13時点)であって、
> 正式な商標調査ではない。最終判断の前に必ず弁理士による調査を行うこと
> (ROADMAP 並走レーンの商標確認タスク)。DNSが解決しない=未登録とは限らない(whois が正式)。

---

## 結論(推奨): 条件付きで People OS を続投する

**いまは変えない。ただし「確定」でもない。** M8(クローズドβ = 初の対外露出)前の
商標確認をゲートとし、下記のフリップ条件に当たったら改名する。

### 理由

1. **対抗馬が、調べたら People OS より強くなかった。**
   有力視していた候補ほど混雑していた(下記調査結果)。既存語の範囲では
   「乗り換える価値のある明確に強い名前」が見つからず、より強くするには
   完全造語に振る必要がある。それは対外露出の前にやれば十分間に合う。
2. **名前はまだ対外の仕事をしていない。** 露出はM8まで無いので、
   いま変えても学習コスト(文書・会話の言い直し)だけが発生する。
3. **改名コストが低いまま保たれている。** 位置づけ整理(07)で実測済み:
   影響は表示文字列のみ、約15ファイル・1コミット。リポジトリ名・`PL_`・URLは不変。
   つまり「後から変える」オプションの価値が高く、急いで決める理由がない。
4. **日本ファーストなら当面のドメイン問題が小さい。** `peopleos.com` は使用中だが、
   `peopleos.jp` はDNS上は未使用(取得可能性あり・whois要確認)。
5. 思想面の適合は引き続き最高評価: 構想書 §9 の到達点そのもので、
   「People OS 憲法」という言葉が既に文書群全体で機能している。

### 認識している弱点(隠さない)

- 英語圏では **"People OS" = 人事・組織管理(People Ops)の一般語**として定着しつつある。
  HR系SaaSの自称・記事タイトルに多用され、`peopleos.health` という実在プロダクトもある。
  **英語圏でこの名のまま出すと「HRツール」と誤読される**可能性が高い。
- 一般語+一般語なので商標の識別力が弱く、検索でも埋もれる。

→ この弱点が実害になるのは「グローバル展開」と「商標出願」の時点。
そこで再検討することをフリップ条件に組み込む。

## 調査結果(2026-08-13 簡易調査)

### People OS(現行)

- 英語圏で "People Operating System" は HRテックの一般ポジショニング語
  (ChartHop「People Ops Platform」等、People Ops 系の製品・記事が多数)
- `PeopleOS`(peopleos.health)— 人材インテリジェンス系の実在プロダクト
- `peopleos.com` 使用中 / **`peopleos.jp` はDNS未使用(可能性あり)**
- 同名の「消費者向けコミュニケーション基盤」は見当たらなかった

### 改名候補の衝突状況

| 候補 | 調査結果 | 判定 |
|---|---|---|
| **Self OS** | `selfos.org` `.ca` `.me` `.club` `self-os.app` + Google Play アプリ + GitHub プロジェクト等、**同名が多数乱立**。.com/.app とも使用中 | **除外**(前回メモで有力としたが、調査で覆った) |
| **Musubi(結び)** | カケハシの薬局DX「Musubi」が**全国6,000店超**で稼働。国内テック文脈では占有済み | **除外** |
| **Yui(結)** | 新生銀行「YUI Platform」/ 地域ICT「結ネット」/「Yui-Base」等、国内で複数使用。`yui.jp` `.app` とも使用中。人名・歌手のノイズも大 | 弱い |
| **Awai(あわい・間)** | 大きな同名サービスは見当たらず。`awai.jp` はDNS未使用(可能性あり)。ただし `awai.com`(米・別業種団体)と、音楽サブスク **AWA** との称呼近似に注意 | **改名するなら第1候補**(称呼近似は弁理士確認) |
| **Enishi(縁)** | 決定的な衝突は未検出。`enishi.jp` DNS未使用 / `.app` 使用中。英語話者に発音しづらい | 次点 |

| Human OS / Life OS / Ties / Commons / Keyring | 一般語すぎる・既存使用・思想とのズレのいずれか | 見送り |

## ⚠️ むしろ優先すべきは機能名「Personal LINK」側の確認

検討の副産物として、**機能名のほうが商標リスクが高い可能性**が見つかった。

1. `personallink.jp` / `personal-link.jp` は**登録済み**(内容・権利者は要確認)
2. 「LINK」は「**LINE**」と外観・称呼が近い(1字違い)
3. その上でタグラインが「**LINEを教える前に**、つながろう」と競合名を直接参照する

比較広告的な文脈+類似名の組み合わせは、商標・不正競争防止の観点で
専門家確認が必須。**M8前の弁理士確認は、プラットフォーム名よりも
機能名 Personal LINK を優先**すること。
